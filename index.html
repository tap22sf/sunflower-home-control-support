Sunflower Home Control

Control compatible home lights and sprinklers on your local network.

SupportPrivacy policy

Before you connect

Requires iOS 17 or later and a compatible ESP32 controller running the Sunflower Home Control phone API on TCP port 3333. This is not a universal controller for all ESP32 devices or commercial smart-home products. No HomeKit hub or cloud account is required.

Use a trusted home Wi-Fi network. The app's controller protocol is not encrypted or authenticated. Never expose port 3333 to the internet.

Get started

  1. Connect your iPhone and compatible controller to the same home network.
  2. Allow Local Network access when iOS asks. You can change this permission in Settings > Privacy & Security > Local Network.
  3. Open the app's gear-shaped Settings button. Enter your controller's hostname or numeric IP address, not a URL. Disconnect before editing the address.
  4. Return to the main page and tap Connect.

Without hardware, tap Try Demo. All demo data and commands are simulated; no real equipment is operated.

Using the controls

  • Tap a station tile to toggle it. Turning ON defaults to 60 minutes for lights and 10 minutes for sprinklers. Turning OFF overrides the schedule until canceled or midnight.
  • Touch and hold a tile for detailed override settings. Durations change in five-minute steps. VoiceOver also provides an Override Settings action.
  • ON tiles display a minutes:seconds countdown based on the controller's reported cutoff time. Unknown cutoff times display --:--.
  • Stop Water holds sprinklers until resumed or midnight. It does not stop lights.
  • Cancel Overrides restores station schedules after confirmation and leaves Stop Water unchanged. Scheduled stations may turn on immediately.

Overrides continue on the controller if the app closes. Reconnect to see current state. Controller restarts clear its in-memory overrides. ON means the last successfully commanded relay state, not independent physical feedback. Only operate equipment when it is safe.

Connection troubleshooting

  • Check power, Wi-Fi, the controller address, and Local Network permission.
  • Guest Wi-Fi isolation, VPNs, or router client isolation can block access.
  • Try the controller's numeric IP address if its hostname does not resolve.
  • The app disconnects when it enters the background. Reconnect on return.
  • If a command times out, it may have executed. Reconnect and review state before issuing another command.
